# e-plantShopping

## Project Name
e-plantShopping

## Description
Paradise Nursery is an online plant shopping application where users can browse plants by category, add plants to a shopping cart, update quantities, and view their cart total.

## Features
- Browse plants organized into categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove items from the cart.
- View the total price of each item and the entire cart.
- Navigate between the Home, Plants, and Cart pages.

## Technologies Used
- React
- Vite
- Redux Toolkit
- JavaScript
- CSS
